## 📌 How to Rename Your Repository on GitHub (e.g. to `Excel-Sales-Dashboard`)

Repository names on GitHub are managed directly on the GitHub website. To rename your repository:

1. Go to your repository on GitHub (`https://github.com/your-username/your-repo-name`).
2. Click on the **⚙️ Settings** tab near the top right of the repository page.
3. In the **Repository name** field under the **General** section, type your new name (for example: `Excel-Sales-Dashboard`).
4. Click the **Rename** button. GitHub will automatically update your repository URL and redirect any old links!

## 🚀 How to Set Up This Repository as Your GitHub Portfolio Profile

1. **Create Your GitHub Profile README:**
   - Create a repository named exactly after your GitHub username (e.g., `https://github.com/your-username/your-username`).
   - Copy the portfolio template below into that repository's `README.md`. It will automatically display on your GitHub profile home page!

2. **Organize Your Data Projects into Repositories:**
   - Create separate repositories for each project (e.g., `Excel-Sales-Dashboard`, `Customer-Churn-SQL-Python`, `Healthcare-EDA`).
   - For each repository, write a clear `README.md` explaining:
     - **Business Problem:** What business question are you answering?
     - **Dataset:** Data source description.
     - **Tools Used:** e.g., Excel (PivotTables, Power Query, DAX), SQL, Python, Tableau, Power BI.
     - **Key Insights & Results:** Actionable takeaways and business impacts.

## 💡 How Recruiters Find Data Analysts

Recruiters search using automated tools like LinkedIn Recruiter and GitHub search filters.

### 1. LinkedIn Recruiter Optimization
* **Headline:** Avoid titles like *"Student"* or *"Job Seeker"*. Use:
  `Data Analyst | SQL, Python, Power BI, Tableau, Excel | Business Intelligence & Data Analytics`
* **Skills & About Section Keywords:**
  - `SQL` (PostgreSQL, MySQL, Snowflake, BigQuery), `Python` (Pandas, NumPy, Matplotlib, Seaborn), `Excel` (DAX, PivotTables, Power Query, VLOOKUP, XLOOKUP), `Power BI`, `Tableau`.
  - `Exploratory Data Analysis (EDA)`, `Data Cleaning`, `ETL Pipelines`, `Dashboarding`, `Business Intelligence`.

### 2. GitHub Search Optimization
* **Topics:** Add topics to your repositories like `excel-dashboard`, `data-analysis`, `sql-queries`, `python-eda`, `powerbi-dashboard`.
